# 📊 Retail Sales Performance Analysis

A retail sales analysis project using **Python, Pandas, NumPy, Matplotlib, Jupyter Notebook, Microsoft Excel, and Power BI**.

This project analyzes retail sales transactions to understand sales performance, products, customers, promotions, discounts, profitability, and sales trends.

The project is divided into two main parts:

1. **Python Data Analysis** — data loading, cleaning, feature engineering, analysis, and visualization.
2. **Power BI Dashboard** — interactive reporting using data modeling, DAX measures, KPIs, slicers, and visualizations.

---

# 📌 Project Overview

The objective of this project is to analyze retail sales data and convert the available transaction data into meaningful business insights.

The project focuses on:

- Sales performance
- Net sales
- Profit
- Product performance
- Customer activity
- Promotion performance
- Discount analysis
- Sales trends
- City-level sales
- Order-level analysis
- Interactive Power BI reporting

The project demonstrates an end-to-end data analytics workflow using both Python and Power BI.
